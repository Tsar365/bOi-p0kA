## ✨ Features
 
- 🏠 **Home** — browse the full book collection
- 📖 **Book Details** — view details for a specific book
- 📝 **Read List** — keep track of books you want to read
- ℹ️ **About** — learn more about the app

## 🚀 Getting Started
 
Clone the repo and install dependencies:
 
```bash
git clone <your-repo-url>
cd boi-p0ka
npm install
```
 
Run the dev server:
 
```bash
npm run dev
```
 
Build for production:
 
```bash
npm run build
```
 
Preview the production build locally:
 
```bash
npm run preview
```
 
## 📁 Project Structure
 
```
src/
├── components/     # Reusable UI components
├── pages/          # Route pages (Home, About, BookDetails, ReadList, ...)
├── routes/         # React Router configuration
├── utility/        # Helper functions
└── assets/         # Images and static assets
public/
└── booksData.json  # Book dataset
```
 
## 📦 Deployment
 
This project is deployed on **Netlify**. To deploy your own version:
 
```bash
npm run build
```
 
Then drag and drop the generated `dist` folder into [Netlify Drop](https://app.netlify.com/drop), or connect the repo to Netlify/Vercel for automatic deploys on every push.
